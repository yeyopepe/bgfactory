Editor reutilizable de ajuste de imagen: la forma de la ficha (aquí circular; sería cuadrada si esa es la forma elegida) actúa como máscara de recorte sobre la imagen del recurso elegido. El usuario arrastra la imagen dentro de la forma para reposicionarla y usa el control de zoom para acercar/alejar. El resultado (offset + zoom) se guarda como ajuste propio de esta ficha; el recurso de imagen original nunca se modifica. Se abre automáticamente tras elegir/cambiar la imagen en design_modal-ficha-especificas.html, y también bajo demanda desde el botón "Ajustar imagen…".
