Editor de cartas — click derecho sobre un cuadro de texto

Nombre de la carta
Eliminar
Colocar arriba
Colocar abajo

El click derecho sobre el cuadro de texto (o sobre una figura, como el círculo morado o el rectángulo naranja del fondo) lo selecciona y abre este menú junto al cursor, reutilizando el mismo componente visual del menú contextual ya usado en modo juego. Las tres filas — Eliminar, Colocar arriba, Colocar abajo — actúan sobre el elemento bajo el que se abrió el menú.
