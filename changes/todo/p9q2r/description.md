## Idea
Nuevo elemento: cartas. Una forma rectangular que puede diseñarse con un editor de cartas.
Son dos cambios importantes:
- Nuevo elemento carta
- Editor de cartas

p9q2r

## Notas
El editor de cartas permite, en una ventana especial, diseñar las dos caras de un carta (frontal y trasera).
Permitirá:
- seleccionar la proporción de la carta. Ofrece un desplegable con los más habituales: 1:1, 2:1 (horizontal o vertical) y algunas otras frecuentes del mercado de juegos de cartas
- Permite editar las dos caras por separado, pero las dos visibles la mismo tiempo
- añadir una imagen y editarla (usa las funcionalides de mover, recortar, etc... que ya existen)
- añadir cuadros de texto, cada uno con su tipo de fuente, tamaño y color. La modificación de estos parámetros para cada cuadro de texto debe poder hacerse haciendo doble clic en el elemento de texto, con una modal
- el diseño de las dos caras de una carta se almacena de la manera que mejor creas, con la posibilidad de modificarlo siempre que el usuario quiera.

Propiedades específicas:
- editar -> editor de cartas
