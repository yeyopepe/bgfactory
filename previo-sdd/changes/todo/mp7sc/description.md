# Idea: mp7sc

## Idea
Exportar juego ofuscado dentro de la app

## Code
mp7sc

## Creation date
2026-08-08

## Notas

Actualmente la exportación de un juego ofuscado se realiza mediante un script externo a la aplicación. La idea es integrar esta funcionalidad directamente dentro de la app, para que el usuario pueda exportar el juego ofuscado sin tener que salir de la interfaz ni ejecutar scripts adicionales.
