Caras de dado en modo "imágenes" — una maqueta por cada silueta existente

La imagen se recorta exactamente a la silueta 2D que ya dibuja el dado según su nº de caras (triángulo, cuadrado, diamante o decágono) — no un recorte cuadrado genérico.

d4 — triángulo (numeroMaximoCaras = 4)

d6 — cuadrado (numeroMaximoCaras = 6)

d8 — diamante (numeroMaximoCaras = 8)

d10 / d12 / d20 / lista de valores — decágono (cualquier otro nº de caras)
